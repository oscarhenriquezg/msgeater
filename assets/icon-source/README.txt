MsgEater icon pack (transparent background)

Contenido:
- png/: PNG sueltos en tamaños 16, 22, 24, 32, 48, 64, 128, 256, 512 y 1024
- linux/hicolor/: estructura lista para Linux (Icon=msgeater)
- macos/MsgEater.iconset/: estructura lista para convertir a .icns en macOS
- macos/MsgEater.icns: archivo listo para usar

Sugerencia macOS:
Si necesitas regenerar el .icns en un Mac, ejecuta:
iconutil -c icns MsgEater.iconset
