MsgEater icon package
=====================

Source: yellow-background MsgEater concept.

PNG/ contains generic PNG sizes:
16, 22, 24, 32, 48, 64, 128, 256, 512 and 1024 px.

macos/MsgEater.iconset/ contains the standard macOS iconset naming:
icon_16x16.png
icon_16x16@2x.png
icon_32x32.png
icon_32x32@2x.png
icon_128x128.png
icon_128x128@2x.png
icon_256x256.png
icon_256x256@2x.png
icon_512x512.png
icon_512x512@2x.png

macos/MsgEater.icns: included

linux/hicolor/ is ready to copy into a standard hicolor icon hierarchy.
Each size uses the filename msgeater.png.

Suggested Linux desktop entry:
Icon=msgeater

Notes:
- The original artwork is raster, so no SVG is included.
- 16–64 px variants received a light sharpening pass after high-quality downsampling for better launcher/menu readability.
